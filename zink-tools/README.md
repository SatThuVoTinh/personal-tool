# Zink Tools

Zink Tools is a thin callable boundary for Excel, Power BI, SQL, Python, n8n and
decision-science capabilities. It is not an orchestrator, workflow-state store,
Knowledgebase, Skill Store, model runtime or generic platform.

Each capability directory is ownership scaffold only in M5/T1-R2. Do not add
training code, serving APIs, registries, evaluation pipelines or specialist
implementations without a separately approved task.
