# Canonical hash fixtures

Synthetic canonicalization vectors for the governance digest.

`vectors.json` holds the vectors and the LITERAL digest each one must
produce. The expectation is pinned in the file (not regenerated by the lane
that reads it), so the lane compares the production canonicalizer against a
fixed truth.

The loader is `tests/m7-t4-orchestration.test.mjs` (the M12/T9 F-220 block).
