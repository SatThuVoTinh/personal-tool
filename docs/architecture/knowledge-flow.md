# Knowledge Flow

```text
External Obsidian Vault (read-only)
  → Connectors
  → Document Processing
  → Knowledge AI: chunking and embedding
  → Indexing
  → Retrieval with filters and citations
  → Knowledge API
```

The vault remains outside this repository. The default source policy follows `AGENTS.md`: `01. Knowledge` is active Knowledge RAG content; Books and Papers are opt-in; Videos and Templates contribute metadata; Notes and Archives are excluded from active retrieval.
