# Knowledge and Skill Flow

```text
Human-owned Obsidian Vault (read-only)
  -> Zink Knowledgebase ingestion/index/retrieval
  -> provenance and citations

Owner-built skill/template candidate
  -> Zink Skill Store governance
  -> owner promotion
  -> ACTIVE

OpenClaw
  -> Zink Tools boundary
  -> SkillAdapter search (ACTIVE-only) / propose (CANDIDATE-only)
  -> durable proposal record
  -> #office owner confirmation (exact content binding)
  -> trusted canonical promotion to ACTIVE
  -> derived pgvector sync (READY)
```

Knowledgebase and Skill Store are separate logical stores. Research and candidate
outputs are evidence until the owner promotes them; neither OpenClaw nor n8n may
perform that promotion implicitly.
