- **Verdict:** **CONFIRMED-AS-LATENT.** The operational Compose file selection and the different hardening settings are directly proven, but no ordinary deployment was rendered or reconciled. The incomplete proof that those controls apply to the normal composition is also a test gap, but F2 best describes the claimed defect.

No exploit path, observed compromise or data loss was demonstrated, and some protections remain (non-root process and read-only Vault), so High is not supported.
